MegaFuse

Mega Bomberman (Hudson, 1994), from its 68000 code translated into Rust.

Kept from last time: . Pick another to replace it.

The ROM stays in this browser and isn't sent anywhere. Keys: arrows, Z X C (A B C), Enter (Start); W A S D, F G H, Tab for pad 2; F2 no sprite limit.

Online

The host starts at once; the others can come in any time, and a seat whose player leaves is free again. Run megafuse-server somewhere everyone reaches (docs/NETPLAY.md). Native players can join the same room.
